# FoodMenu pages

Local base URL: `http://localhost:3000` (run the app with `npm run dev`).

## Main pages

Copy any URL below into a browser:

```text
http://localhost:3000/
http://localhost:3000/features
http://localhost:3000/contact
http://localhost:3000/auth
http://localhost:3000/user
http://localhost:3000/admin
```

`/user` requires a restaurant owner account; `/admin` requires an administrator account.

## Dynamic page patterns

```text
http://localhost:3000/<restaurant-slug>
http://localhost:3000/<restaurant-slug>/<menu-slug>
http://localhost:3000/menu/<menu-id>
```

The last URL opens the owner-only menu editor. Menu IDs are generated by MongoDB; open a menu from `/user` to get its exact URL.
