# План улучшения FoodMenu

Основа диплома: управление данными ресторанов и электронными меню, роли владельца и администратора, публичный доступ через QR-код.

## 1. Лендинг и публичные страницы

- [x] Сохранена палитра: тёмно-зелёный, тёплый кремовый, оранжевый акцент.
- [x] Пересобраны первый экран, навигация, блок процесса, возможности и футер; убраны ссылки на вход.
- [x] Обновлены страницы Features, Contact и авторизации; заявки сохраняются в MongoDB.
- [x] Добавлены оригинальные ресторанные фотографии в оптимизированном WEBP.

## 2. Панели управления

- [x] Разделены рестораны, меню и профиль; добавлены фильтр по ресторану и ясные статусы.
- [x] Создание и редактирование открываются в модальных окнах; после создания меню открывается его редактор.
- [x] В редакторе показаны выбранные раздел и категория, блюда редактируются в отдельной форме; дополнительные поля свёрнуты.
- [x] Обновлена главная админка: рестораны, владельцы, статусы и входящие заявки.
- [x] Сайдбар ограничен высотой окна браузера и прокручивается отдельно.

## 3. Страница ресторана и меню

- [x] Упрощён стиль меню, улучшены карточки блюд, цены и вид на узком экране.
- [x] Страница ресторана оформлена отдельно; сезонные меню представлены как коллекция.
- [x] В локальной MongoDB: 3 ресторана, 6 сезонных/специальных меню, разделы Food/Drinks, категории и блюда; цены EUR, у каждого блюда фото.

Референсы: [Aurelia Dining](https://www.framer.com/marketplace/templates/aurelia-dining/) (редакционная композиция), [SOEN](https://www.framer.com/marketplace/templates/soen/) (типографика), [Golden Crane](https://www.framer.com/marketplace/templates/golden-crane/) (сдержанная анимация); [Toast Menu Manager](https://support.toasttab.com/en/article/Get-Started-With-Menus?lang=en_US) (структура редактора). Демо: `node scripts/seed-demo.mjs`; для обновления этих шести демо-меню — `--refresh`.

Фотографии созданы через встроенный imagegen: стол с пастой, сезонные овощи, лимонный тарт, пицца маргарита, круассан с кофе, винная доска. Промпты: реалистичная редакционная ресторанная съёмка, естественный свет, нейтральный интерьер с оливковыми оттенками, без людей, логотипов и текста.
